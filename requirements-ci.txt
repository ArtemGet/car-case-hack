# CI (CPU-only) dependency lock — exact pins. No ">=" anywhere.
#
# Scope: lint + unit tests (`tests/`, `reid/**`, `service/**`) on a CPU-only
# GitHub Actions runner. This is deliberately NOT the GPU/runtime lock
# (`requirements-runtime.txt`) nor the full training stack (`requirements.txt`):
# the GPU/training extras (onnxruntime-gpu, optuna, tensorboard, matplotlib,
# scikit-learn, opencv-python, faiss-cpu, onnx, timm, transformers) are not
# imported by the test suite and are intentionally excluded.
#
# TORCH IS CPU-ONLY HERE. The torch/torchvision pins below must be installed
# from the CPU wheel index, not PyPI (PyPI's default wheels are CUDA builds,
# hundreds of MB larger):
#     python -m pip install --index-url https://download.pytorch.org/whl/cpu \
#         torch==2.6.0 torchvision==0.21.0
# `.github/workflows/ci.yml` does exactly that in a dedicated step BEFORE
# `pip install -r requirements-ci.txt`; a subsequent plain install then sees
# them satisfied (==2.6.0 accepts the installed 2.6.0+cpu local version).
#
# Requirements are CPU-only; runtime base is Python 3.12 (see Dockerfile).
